# 题库答题系统产品需求清单

## 1. 产品定位

建设一个题库答题系统，包含管理平台和用户答题端。

管理平台用于维护题目分类、题目、用户、分类授权和答题记录。用户端用于用户登录、查看被授权的题目分类、在线答题、提交答卷并查看成绩。

用户端需要同时兼容 H5 和 PC 页面样式。

## 2. 角色说明

| 角色 | 说明 |
| --- | --- |
| 管理员 | 使用管理平台，维护题库分类、题目、用户、授权关系和答题记录 |
| 普通用户 | 使用用户端，登录后查看被授权的题库分类并答题 |

## 3. 管理平台需求

### 3.1 管理员登录

| 功能 | 说明 |
| --- | --- |
| 管理员登录 | 管理员通过账号、密码登录管理后台 |
| 登录状态管理 | 登录后保持会话，未登录访问后台页面时跳转登录页 |
| 退出登录 | 管理员可主动退出系统 |

### 3.2 题目分类管理

管理员可以增删改查题目分类，例如“高级架构题库”。

| 功能 | 说明 |
| --- | --- |
| 分类列表 | 展示所有题目分类 |
| 新增分类 | 支持创建题目分类 |
| 编辑分类 | 支持修改分类名称、描述、排序、状态 |
| 删除分类 | 支持删除分类；删除前需要判断分类下是否已有题目 |
| 分类启用/禁用 | 禁用后用户端不可见，不允许答题 |
| 分类搜索 | 支持按分类名称搜索 |
| 分类排序 | 支持配置分类展示顺序 |

建议字段：

| 字段 | 说明 |
| --- | --- |
| 分类名称 | 必填，例如“高级架构题库” |
| 分类描述 | 可选，用于说明题库内容 |
| 排序值 | 可选，用于控制展示顺序 |
| 状态 | 启用 / 禁用 |
| 创建时间 | 系统自动生成 |
| 更新时间 | 系统自动生成 |

### 3.3 题目管理

管理员可以基于题目分类录入题目，支持单选题、多选题和问答题。

| 功能 | 说明 |
| --- | --- |
| 题目列表 | 按分类查看题目列表 |
| 新增题目 | 基于某个题目分类录入题目 |
| 编辑题目 | 修改题干、选项、答案、解析、分值等 |
| 删除题目 | 删除指定题目 |
| 题目搜索 | 支持按题干关键字、题型、分类搜索 |
| 题目启用/禁用 | 禁用题目不参与用户答题 |
| 题目排序 | 支持配置题目在答题时的展示顺序 |
| 答案配置 | 根据题型配置正确答案 |
| 分值配置 | 每道题可配置分数 |

支持题型：

| 题型 | 说明 |
| --- | --- |
| 单选题 | 多个选项中只有一个正确答案 |
| 多选题 | 多个选项中有多个正确答案 |
| 问答题 | 用户输入文本答案，可配置参考答案 |

题目通用字段：

| 字段 | 说明 |
| --- | --- |
| 所属分类 | 必填 |
| 题型 | 单选题 / 多选题 / 问答题 |
| 题干 | 必填 |
| 选项 | 单选题、多选题必填 |
| 正确答案 | 单选题、多选题必填；问答题可填参考答案 |
| 答案解析 | 可选 |
| 分值 | 必填，默认可为 1 分 |
| 排序 | 可选 |
| 状态 | 启用 / 禁用 |
| 创建时间 | 系统自动生成 |
| 更新时间 | 系统自动生成 |

问答题第一版建议只保存用户答案和参考答案，不做自动评分。后续可以扩展人工评分或 AI 辅助评分。

### 3.4 题目分类授权

管理员可以给用户授权题目分类，控制用户可以看到哪些题库分类。

| 功能 | 说明 |
| --- | --- |
| 用户列表 | 展示系统用户 |
| 分类授权 | 给用户授权可访问的题目分类 |
| 取消授权 | 移除用户对某个分类的访问权限 |
| 批量授权 | 支持给多个用户授权同一个分类 |
| 查看授权结果 | 查看某个用户已授权的题库分类 |
| 用户端权限生效 | 用户只能看到已授权且启用的分类 |

授权规则：

| 规则 | 说明 |
| --- | --- |
| 未授权不可见 | 用户端不展示未授权分类 |
| 分类禁用不可见 | 即使已授权，分类禁用后也不展示 |
| 题目禁用不参与答题 | 分类下禁用题目不展示 |
| 授权变更即时生效 | 用户刷新页面后看到最新授权结果 |

### 3.5 用户管理

| 功能 | 说明 |
| --- | --- |
| 用户列表 | 查看所有用户 |
| 新增用户 | 创建用户账号 |
| 编辑用户 | 修改昵称、手机号、状态等 |
| 重置密码 | 管理员可重置用户密码 |
| 禁用用户 | 禁用后用户无法登录 |
| 删除用户 | 按业务需要决定是否支持物理删除 |

建议字段：

| 字段 | 说明 |
| --- | --- |
| 用户名 | 登录账号，唯一 |
| 密码 | 加密存储 |
| 昵称 | 展示名称 |
| 手机号 | 可选 |
| 状态 | 启用 / 禁用 |
| 创建时间 | 系统自动生成 |
| 更新时间 | 系统自动生成 |

### 3.6 答题记录管理

| 功能 | 说明 |
| --- | --- |
| 答题记录列表 | 查看用户提交记录 |
| 记录详情 | 查看用户每道题的作答情况 |
| 分数查看 | 查看总分、得分、正确率 |
| 按用户筛选 | 查看某个用户的答题历史 |
| 按分类筛选 | 查看某个题库分类的答题情况 |

## 4. 用户端需求

用户端需要兼容 H5 和 PC。

### 4.1 用户登录页面

| 功能 | 说明 |
| --- | --- |
| 账号密码登录 | 用户输入账号、密码登录 |
| 表单校验 | 账号和密码不能为空 |
| 登录失败提示 | 账号不存在、密码错误、账号禁用等提示 |
| 登录成功跳转 | 登录成功后进入题库分类页 |
| 登录状态保持 | 已登录用户再次访问可直接进入系统 |
| 退出登录 | 用户可退出当前账号 |

页面适配要求：

| 端 | 要求 |
| --- | --- |
| H5 | 适配手机屏幕，表单居中，按钮易点击 |
| PC | 页面宽度适中，视觉简洁 |

### 4.2 题目分类列表

用户登录后，可以看到自己被授权的题目分类。

| 功能 | 说明 |
| --- | --- |
| 展示授权分类 | 用户登录后只看到自己被授权的题目分类 |
| 分类信息展示 | 展示分类名称、描述、题目数量 |
| 无数据提示 | 没有授权分类时显示友好提示 |
| 点击进入答题 | 点击某个分类后进入答题页面 |

展示规则：

| 条件 | 结果 |
| --- | --- |
| 用户未授权 | 不展示该分类 |
| 分类被禁用 | 不展示该分类 |
| 分类下没有启用题目 | 可展示“暂无题目”或禁止进入 |

### 4.3 答题页面

用户点击题目分类后，可以开始答题。

| 功能 | 说明 |
| --- | --- |
| 加载题目 | 根据分类加载该分类下启用题目 |
| 单选题作答 | 用户选择一个选项 |
| 多选题作答 | 用户可选择多个选项 |
| 问答题作答 | 用户输入文本答案 |
| 题目进度 | 显示当前题号 / 总题数 |
| 上一题 / 下一题 | 支持题目切换 |
| 未答提示 | 提交前提示还有未答题目 |
| 提交答卷 | 全部题目做完后提交答案 |

建议交互：

| 场景 | 说明 |
| --- | --- |
| H5 | 一屏展示一道题，底部固定操作按钮 |
| PC | 左侧可展示题号导航，右侧展示题目内容 |
| 提交前 | 弹窗确认是否提交 |
| 提交后 | 跳转成绩页 |

### 4.4 成绩页面

全部题目做完并上传提交后，用户可以看到分数。

| 功能 | 说明 |
| --- | --- |
| 展示总分 | 显示用户本次答题得分 |
| 展示满分 | 显示该分类总分 |
| 展示正确率 | 显示答对题数 / 总题数 |
| 查看答题详情 | 展示每道题用户答案、正确答案、解析 |
| 返回分类列表 | 支持回到题库分类列表 |
| 再答一次 | 可选，支持重新答题 |

成绩计算规则：

| 题型 | 计分方式 |
| --- | --- |
| 单选题 | 用户答案等于正确答案则得分 |
| 多选题 | 用户选择与正确答案完全一致才得分 |
| 问答题 | 第一版建议不自动计分，只保存答案和展示参考答案 |

## 5. 通用业务规则

| 规则 | 说明 |
| --- | --- |
| 用户只能访问被授权分类 | 后端接口必须校验权限，不能只靠前端隐藏 |
| 禁用数据不可参与答题 | 禁用分类、禁用题目不展示 |
| 答题提交后生成记录 | 每次提交保存一条答题记录 |
| 答案提交后不可修改 | 默认提交后答题记录固定 |
| 分数由后端计算 | 避免前端篡改分数 |
| 密码加密存储 | 不允许明文保存密码 |

## 6. 第一版 MVP 范围

第一版建议先实现以下功能：

1. 管理员登录
2. 用户管理
3. 题目分类增删改查
4. 题目增删改查，支持单选、多选、问答
5. 用户分类授权
6. 用户登录
7. 用户查看授权分类
8. 用户在线答题
9. 用户提交答卷
10. 自动计算单选、多选分数
11. 成绩页展示分数和答题详情

## 7. 后续增强方向

| 功能 | 说明 |
| --- | --- |
| 问答题人工评分 | 管理员可以对问答题进行人工评分 |
| AI 辅助评分 | 对问答题答案进行相似度判断和评分建议 |
| 错题本 | 用户可以查看错题并重新练习 |
| 答题统计 | 统计用户答题次数、正确率、分类掌握情况 |
| 批量导入题目 | 支持 Excel、Markdown、JSON 导入 |
| 题目随机组卷 | 从分类中随机抽题组成试卷 |
| 限时答题 | 给题库或试卷配置答题时间 |
